# ledger

**AI-assisted writing, with full observability.**

> Status: alpha. This README describes what ledger is for. Nothing is built yet, and everything here may change.

## Why

More and more writing is made with AI. Readers usually can't tell how much, or how it happened. ledger's starting point is that AI-assisted writing can be honest if the reader can see the whole process.

## What it does

### Prompt history for every post

The first feature: for any post written with ledger, a reader can see the full prompt history that produced it, every prompt and every response, in order. Nothing is summarised or hidden. The reader can follow how the piece was made from first draft to published text.

### Style guides

Writers can build a style guide in two ways:

- **From samples:** give ledger examples of your writing, and it drafts a guide from them.
- **Directly:** write or edit the rules yourself.

The guide then shapes the AI's help, so the result sounds like you.

## Ideas for later

Possible next features, none of them committed:

- **AI detection:** an estimate of how much of a text is AI-generated.
- **Plagiarism detection:** checks for text copied from other sources.
- **Source labelling:** automatically marking claims with where they came from.
- Others as the project develops.
